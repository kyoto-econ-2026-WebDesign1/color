## 🧠 解説

### 1. 光の三原色（RGB）

パソコンやスマホの画面は、とても小さな **赤（Red）・緑（Green）・青（Blue）** の光の点が集まってできています。
この3色の光の強さを変えることで、すべての色を表現しています。頭文字をとって **RGB** と呼びます。

| 混ぜる光 | できる色 |
| --- | --- |
| 赤 ＋ 緑 | 黄（イエロー） |
| 緑 ＋ 青 | シアン（水色） |
| 赤 ＋ 青 | マゼンタ（赤紫） |
| 赤 ＋ 緑 ＋ 青 | 白 |
| なにもなし | 黒 |

> **絵の具との違い**
> 絵の具は混ぜるほど暗くなります（**減法混色**）。
> 光は混ぜるほど明るくなります（**加法混色**）。
> 画面の色を考えるときは「光の足し算」で考えるのがポイントです。

### 2. 明るさは 0〜255

コンピューターは、それぞれの光の明るさを **0〜255 の256段階** で表します。

- `0` … ライトが消えている
- `128` … だいたい半分
- `255` … ライト全開

3色それぞれが256段階なので、表せる色は
**256 × 256 × 256 ＝ 約1677万色** になります。

CSS では次のように書けます。

```css
color: rgb(255, 128, 0);   /* 赤255・緑128・青0 → オレンジ */
```

### 3. 16進数

ふだん使う **10進数** は `0〜9` の10種類で数え、9の次でケタが上がります。
**16進数** は `0〜9` のあとに `A〜F` を使い、16種類で数えます。

| 16進数 | 0 | 1 | … | 9 | A | B | C | D | E | F |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 10進数 | 0 | 1 | … | 9 | 10 | 11 | 12 | 13 | 14 | 15 |

2ケタの16進数は「**左のケタ × 16 ＋ 右のケタ**」で10進数になります。

```
FF = 15 × 16 + 15 = 255
80 =  8 × 16 +  0 = 128
1A =  1 × 16 + 10 =  26
```

2ケタの16進数は `00`〜`FF`、つまり **0〜255 をちょうど表せる** ので、色を表すのにぴったりなのです。

### 4. HEXカラーコード

HEX（ヘックス）は「16進数（hexadecimal）」の略です。
HEXカラーコードは、**`#` のあとに赤・緑・青の明るさを2ケタずつ並べたもの**です。

```
#  FF   80   00
   ↑    ↑    ↑
   赤   緑   青
```

| HEX | rgb() | 色 |
| --- | --- | --- |
| `#FF0000` | rgb(255, 0, 0) | 赤 |
| `#00FF00` | rgb(0, 255, 0) | 緑 |
| `#0000FF` | rgb(0, 0, 255) | 青 |
| `#FFFF00` | rgb(255, 255, 0) | 黄 |
| `#FFFFFF` | rgb(255, 255, 255) | 白 |
| `#000000` | rgb(0, 0, 0) | 黒 |
| `#808080` | rgb(128, 128, 128) | グレー |

**覚えておくと便利なこと**

- 3色が **同じ数字** → 白・グレー・黒のどれか（無彩色）
- 数字が **大きいほど明るい**、小さいほど暗い
- 大文字・小文字はどちらでもOK（`#ff0000` と `#FF0000` は同じ）
- 同じ文字が2つずつ並ぶときは3ケタに省略できる（`#FF0000` → `#F00`）

## 💻 コードの読みかた（学生向け）

### HTML と JavaScript のつながり

HTML のボタンや入力欄に `onclick` や `oninput` が書いてあります。

```html
<button onclick="toggleLight('red')">赤のライト</button>
```

これは「クリックされたら `script.js` の `toggleLight` 関数を動かす」という意味です。
`script.js` で同じ名前の `function` を探してみましょう。

### script.js で使っている命令はこれだけ

| 書きかた | 意味 |
| --- | --- |
| `document.getElementById('id名')` | HTMLの部品を id で見つける |
| `部品.value` | 入力欄やスライダーの値を読む |
| `部品.textContent = '文字'` | 表示されている文字を書きかえる |
| `部品.style.backgroundColor = '#FF0000'` | 背景色を変える |
| `部品.classList.toggle('off')` | クラスをつけたり外したりする |
| `数.toString(16)` | 10進数 → 16進数の文字 |
| `parseInt('FF', 16)` | 16進数の文字 → 10進数 |

### CSS と exercise.css

- `style.css` の中にもたくさんのHEXカラーがあります。どんな色か想像しながら読んでみましょう。
- `exercise.css` は `style.css` の **あとに** 読み込んでいるので、同じ箱に色を指定すると `exercise.css` が優先されます。
- `#______` のままだとCSSとして正しくないため、ブラウザはその行を無視します。だから最初は点線の箱のままです。
